# HawkNext

Desktop agent workbench for Office + Coding.

- **Shell:** fork of [ZCode](https://github.com/zai-org/ZCode) (deep rebrand, Apache-2.0)
- **Skin:** HawkBrain UI tokens
- **Harness:** dual driver — `codex` (Office pipeline) + `zcode` (coding default)
- **Models:** llmapi `Auto` / MiMo (hawkren primary, ashawk fallback)
